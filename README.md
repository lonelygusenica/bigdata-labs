# Учебные работы по Big Data

В этом репозитории собраны материалы и практические работы по курсу Big Data. Здесь есть задания по базам данных и инструментам обработки данных: MySQL, MongoDB, Hadoop, Spark, PySpark и ClickHouse.

Основные файлы находятся в папке [bigd_course](bigd_course/README.md). Внутри неё каждая тема хранится отдельно. В папках есть ноутбуки, SQL-запросы, отчёты, примеры данных и файлы для запуска окружения.

Чтобы посмотреть конкретную работу, откройте README в папке нужной темы. Для запуска некоторых работ используется Docker Compose; команды и состав окружения указаны рядом с файлами проекта.

Файл [Задания.pdf](Задания.pdf) содержит исходные задания курса.
