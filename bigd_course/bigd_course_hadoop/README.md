# Hadoop

В этой папке собраны работы по Hadoop: HDFS, MapReduce и Hive. Для MapReduce есть примеры подсчёта слов и длины слов, а также поиск самых частых слов. Отчёты по выполненным работам находятся рядом с заданиями.

Окружение запускается через `docker-compose.yaml`. Данные для практики лежат в `files`, настройки Hadoop — в `config`, программы MapReduce — в `mapreduce`.
