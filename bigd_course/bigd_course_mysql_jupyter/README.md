# MySQL и Jupyter

В этой папке собраны практические работы с MySQL и Python. В ноутбуках рассматриваются SQL-запросы, подключение к базе и обработка данных с Pandas. Также здесь есть SQL-скрипт, наборы данных и материалы по базе Sakila.

Окружение описано в `docker-compose.yaml` и `Dockerfile`. Зависимости Python перечислены в `requirements.txt`.
