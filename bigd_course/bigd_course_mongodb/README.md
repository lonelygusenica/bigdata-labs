# MongoDB

Здесь находятся задания и примеры по MongoDB. В работе создаются базы и коллекции, добавляются и изменяются документы, выполняются запросы по данным о странах.

В папке `work` лежат материалы и изображения к заданиям. В `samples` находятся примеры документов. Настройки запуска MongoDB находятся в `docker-compose.yaml`.
