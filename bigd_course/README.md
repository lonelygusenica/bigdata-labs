# Материалы курса

В папках собраны практические работы по разным инструментам. В каждой теме лежат материалы задания, выполненная работа и файлы окружения, если они нужны.

| Папка | Что внутри |
| --- | --- |
| `bigd_course_mysql_jupyter` | MySQL и работа с данными в Python и Pandas через Jupyter |
| `bigd_course_mongodb` | Практика с базами, коллекциями и запросами MongoDB |
| `bigd_course_hadoop` | HDFS, MapReduce и Hive |
| `bigd_course_hadoop_old` | Отдельные материалы по работе с HDFS |
| `bigd_course_spark` | Работа с RDD в Apache Spark |
| `bigd_course_pyspark_local` | Обработка данных с PySpark локально |
| `bigd_course_clickhouse` | SQL-запросы и данные для ClickHouse |

Для запуска окружения перейдите в папку темы и используйте её `docker-compose.yaml`. Состав сервисов может отличаться в разных работах.
